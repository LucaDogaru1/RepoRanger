Summary:
As a content operations team

I want imported sports events from an external XML feed to preserve the original provider category

so that editors can filter and review imported content more reliably in the CMS.

Details:

A nightly import job receives an XML feed from an external provider.

Each event item contains:
- externalId
- title
- startTime
- sportType
- providerCategory
- providerCompetitionId

Currently, providerCategory is ignored during import.

Requirements:

1. Parse providerCategory from the XML feed.
2. Store providerCategory on the imported event content.
3. Do not overwrite manually edited categories in the CMS.
4. Only apply this behavior to newly imported events.
5. Existing events should keep their current category unless providerCategory is missing locally.
6. Show providerCategory in the CMS event detail page.
7. Add tests for XML import mapping.

Acceptance Criteria:

- XML feed import reads providerCategory.
- New imported events persist providerCategory.
- Existing manual category edits are not overwritten.
- CMS detail view displays providerCategory.
- Import still works when providerCategory is missing.
