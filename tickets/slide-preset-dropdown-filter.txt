Slide preset dropdown — hide archived presets in CMS

As a CMS editor
I want the slide preset picker to only show active presets
So that I cannot assign archived layouts to a slide by mistake

Background
The page manager uses SlidePresetDropdown when configuring slide cells.
The component loads presets via the slide-presets API on mount.
Today the dropdown lists every preset including archived ones (status ARCHIVED).

Scope
Frontend (Vue)
- SlidePresetDropdown: filter out presets where status is ARCHIVED before rendering options
- If the API already excludes archived items, show an empty-state message when no presets remain
- Preserve current behaviour for the selected preset when editing an existing slide

Backend (API)
- GET /slide-presets should not return archived presets by default (optional query ?include_archived=1 for admin tools)
- Response shape unchanged; only filter the collection

Acceptance criteria
- Archived slide presets do not appear in the CMS dropdown
- Active presets still load on first open
- Existing slides that reference an archived preset still display correctly in read-only preview
- API returns 200 with filtered list for default request

Technical notes
- Preset status field exists on the slide preset model
- fetchSlidePresets / slidePresets client module calls GET /slide-presets
- SlidePresetsController::index builds the collection returned to the frontend

Out of scope
- Bulk archive workflow
- Public frontend preset picker (homepage hero)
